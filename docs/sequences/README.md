# 毛绒角色序列网页

入口为 index.html。提醒页展示宽坐姿 IP；开始后请求摄像头，切换到花园跟练场景。三组动作各 50 次，完整动作由本地 MediaPipe 和既有 MotionCounter 判断。没有手动加次数、自动模拟计数或无摄像头完成入口。允许暂停和紧急退出，退出不计完成。

角色动画和人体计数相互独立：角色的演示循环不会增加人体动作次数。声音可开关，减少动态偏好下停在关键帧。结束或退出停止镜头。

三段用户 MOV 仅用于分析动作，没有作为网站公开视频上传。工作台为可滚动的 DOM 示例，不是原始网站截图；安装扩展后会覆盖实际工作网页。花园使用已有去字环境图。

每组动画含 16 帧，由图片生成工具重绘，使用 ffmpeg 去除品红底后以实际 Alpha PNG 合成；没有用截图当主体或把插值放大冒充新帧。提醒页另外生成高精度双帧素材。原始输出保留在本机生成目录。

已有单元测试覆盖三组完整动作、掉帧、人物离开、半动作、丢失识别和计数持久化。新增网页验证覆盖序列播放、镜头拒绝、零计数、退出恢复、再次开始、手机尺寸，以及虚拟摄像头本地推理和释放。

角色为生成重绘，有跨帧外形与毛发细节变化；不能当作与原 IP 像素一致的影视级动画。正式使用前仍需真人摄像头试练。
