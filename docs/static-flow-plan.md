# 静态动作版流程

已获用户授权：先生成核心动作静态图片，后续替换为视频，先跑通整体流程。

- 六张独立角色资产：坐姿占屏、站立准备、大鹏展翅、上下齐发、扭转乾坤、完成挥手。
- 三动作每项默认 50 次；未提供动作视频前，动作规则仅作为产品示意。
- 自动演示：不调用摄像头，清楚显示演示计数，不计入真实完成统计；自动串起等待、倒数、三动作、休息/恢复、退场。
- 摄像头模式：本地手部识别 OK 开始/恢复、脸侧张掌暂停、暂停时双掌结束；上半身姿态试验性计数。不把 OK 当站立确认。
- 资源清单统一记录 poster/video，未来只填 video 即可替换静态图。
- 手势按钮保留为桌前兜底，自动演示能独立验证全部页面状态。
- 保留现有网页遮挡、快照、提醒、完成/跳过区分。
