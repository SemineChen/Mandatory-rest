# 当前样式和视频接入

本轮已修改 `public/break.html`，新增 `public/garden.css`、`src/mascot-media.js`。构建结果已更新至 dist。

## 视频接入

左侧角色与右侧摄像头是独立视频元素。左侧 `#mascot-video` 静音循环播放，右侧 `#video` 继续采集摄像头用于原有本地动作识别。

在 `src/mascot-media.js` 的 `MASCOT_CLIPS` 配置本地文件路径：idle（待机）、confused（等待入镜）、open（大鹏展翅）、updown（上下齐发）、twist（扭转乾坤）、celebrate（完成）。视频放在 public/assets 下，再运行构建。所有片段应采用同一透明画布和脚底锚点。建议为目标 Chrome 提供支持 Alpha 的 WebM；实际透明度需用最终素材测试。

目前没有视频文件；未配置路径不会请求不存在的文件。播放失败或对应状态未配置时回退现有 3D 角色。实际视频加载成功前保留回退，防止闪空。摄像头逻辑与角色视频互不混用。
