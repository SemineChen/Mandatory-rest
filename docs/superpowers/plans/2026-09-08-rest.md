# 歇一会 Implementation Plan

> Execute inline with superpowers:executing-plans, task-by-task.

**Goal:** Deliver an installable Chrome extension with local pose recognition and animated Blender mascot.
**Architecture:** MV3 service worker owns persisted sessions and alarms. Content script shields ordinary web pages. Extension break page owns camera/pose processing and Three.js rendering; popup controls schedule.
**Tech Stack:** JavaScript, esbuild, Three.js, MediaPipe, Node test, Playwright.
**Spec:** docs/superpowers/specs/2026-09-08-rest-design.md

## Global Constraints
- Default interval 60 minutes; 3 repetitions per action.
- Camera frames stay local; bundle code, WASM and model.
- Emergency skip never increments completed sessions.
- Preserve existing Blender scene objects.
