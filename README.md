# 禁止久坐 · 你的休息搭子

可本地安装的 Chrome Manifest V3 扩展。默认每 60 分钟提醒休息，通过普通网页遮挡与独立休息页，引导大鹏展翅 50 次 → 3 秒换动作提示 → 上下齐发 50 次 → 3 秒换动作提示 → 扭转乾坤 50 次 → 完成。

## 安装
1. 打开 Chrome，在地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **dist** 文件夹。
4. 把「禁止久坐」固定到工具栏，点击「现在休息一下」体验。
5. 首次开始时允许摄像头。在系统隐私设置中，Chrome 也需要摄像头权限。

休息间隔可选 25、45、60、90、120 分钟。默认 60 分钟。临时暂停可选 30 分钟、1 小时或直到手动恢复；手动恢复入口在工具栏弹窗。紧急退出不计完成。

## 使用动作识别
- 调整到舒适的距离，让肩膀和手肘进入画面，保持光线充足。手腕出框时改用手肘；仅一侧手臂可见时按该侧动作辅助计数，不验证不可见侧。
- 大鹏展翅：双臂展开至肩高，再放下，计 1 次。
- 上下齐发：一手上举、一手下伸，左右各做一次，计 1 次。
- 扭转乾坤：上身向左转、向右转、回正，计 1 次；只需双肩清晰可见。
- 取消定时保持，每个方向由连续两帧确认后推进，自然连贯动作即可。完整循环才计 1 次；单帧抖动不计数，不把不同侧的半次动作拼成一次。
- 识别不清、暂停或切换标签会取消未完成的半次动作，保留已完成次数。
- 姿态分析在独立 Worker 中运行，同一时间仅处理一帧，最高约 15 次/秒；摄像头目标 480×360、15 帧/秒，角色约 30 帧/秒，减少绒毛与阴影开销。
- 摄像头权限被拒绝、设备断开时可重试或紧急退出。
- 结束、跳过或关闭休息页会停止摄像头；关闭休息页本身不会结束当前休息，从遮挡页可重新进入。

## 文件
- `dist/`：可安装扩展，无需运行开发服务器。
- `歇一会-Chrome插件.zip`：同一扩展的压缩包，解压后加载里面的 dist 文件夹。
- `public/assets/mascot-source.blend`：Blender 源文件，模型在 XieYiHui_Mascot 集合；保留原场景物体。
- `public/assets/mascot.glb`：仅小怪兽的实时三维模型。
- `src/mascot.js`：呼吸、眨眼、伸展、疑惑、庆祝动画与轻量短绒毛。
- `artifacts/`：界面截图与验证结果。

## 隐私与权限
所有 JS、WASM 和姿态识别模型随扩展打包。运行时不从 CDN 加载代码，不上传摄像头画面，也不保存视频或人体关键点。仅持久保存休息间隔、下一次提醒、当前动作次数和累计完成组数。休息触发前会截取当前普通网页的可见画面，作为压暗背景，临时放在浏览器会话内存中，完成或跳过后清除会话缓存；完成页仍保留当前显示画面，点击返回或关闭页面时释放，不上传或写入文件。

`storage` 保存上述设置；`alarms` 定时；`tabs` 查找/聚焦休息页；`scripting` 在安装时为已打开的普通网页添加遮挡；`<all_urls>` 网站权限用于网页遮挡和 Chrome 的可见标签页截图接口；代码仅截取 HTTP/HTTPS 网页，不提取正文。

## 实际边界
- 这是浏览器休息辅助工具，不是操作系统锁屏或防篡改软件。Chrome 内置页面、扩展商店、其他应用及未授权的隐身窗口不被遮挡。用户仍能退出/禁用扩展。
- 默认定时按经过时间运行，不扣除离开电脑的时间；电脑休眠期间不会唤醒，恢复后由 Chrome 处理到期提醒。
- 姿态计数是基于关节点的启发式规则，不是医疗级动作评估。实际识别效果取决于取景、光照、衣物与身体姿态；只在舒适范围内动作。
- 本版角色已按占屏参考图改为更宽的坐姿，并补充脚掌肉垫，是重新制作的实时三维形象，使用短绒毛效果，并非参考图中的摄影级长毛质感。Blender 的节点噪声材质不会直接携带到 GLB，WebGL 端补充表面与绒毛。

## 开发与验证
需要 Node.js 20+ 和 Python 3（仅本地预览）。

```sh
npm ci
npm test
npm run build
npm run preview
```

预览地址：http://localhost:4173/break.html 。普通网页预览不具有跨标签遮挡能力。

在预览服务运行时：
```sh
node scripts/smoke.mjs
node scripts/extension-smoke.mjs
```

浏览器测试使用独立 Chromium 配置与虚拟摄像头，不访问真实用户摄像头。覆盖扩展实际加载、跨标签遮挡、本地模型/WASM 初始化与推理、跳过恢复、摄像头释放以及连续休息状态。动作全流程使用合成关节点单元测试；真人动作识别的准确率仍需安装后实际取景验证。

Three.js 使用 MIT 许可；MediaPipe 使用 Apache-2.0 许可。安装包附带依赖许可说明。姿态模型来源：https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task 。
